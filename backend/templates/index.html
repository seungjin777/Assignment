FastAPI 백엔드 1주차 과제

FastAPI를 처음 접하는 분들을 위한 단계별 실습 과제입니다.
왼쪽 목차에서 단계를 선택하면 상세 내용을 볼 수 있습니다.

1단계: 페이지 보여주기

목표: FastAPI에서 HTML 페이지를 반환하는 방법을 익힙니다.
  • /에서 index.html 반환
  • /hello/자신의이름에서 hello.html 반환 (이름은 반드시 자신의 이름으로!)
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명템플릿에서 받는 데이터
GET/index.html메인 랜딩 페이지(HTML) 반환없음
GET/hello/자신의이름hello.html이름을 받아 인사 페이지 반환
템플릿에서 {{ name }}으로 사용		{ name: str }
예: { name: "홍길동" }
  • hello.html에서는 {{ name }} 변수로 이름을 받아 화면에 출력합니다.
Jinja2Templates란?
Jinja2Templates는 FastAPI에서 HTML 템플릿에 데이터를 넣어주는 도구입니다.
  • 템플릿 파일(예: hello.html)에 {{ name }}처럼 변수를 쓸 수 있습니다.
  • FastAPI에서 templates.TemplateResponse("hello.html", {"request": request, "name": "홍길동"})처럼 데이터를 넘기면, {{ name }} 자리에 "홍길동"이 들어갑니다.
  • 템플릿 파일은 templates/ 폴더에 저장합니다.
Jinja2Templates 기본 예제 
from fastapi.templating import Jinja2Templates
from fastapi import Request
from fastapi.responses import HTMLResponse

app = FastAPI()
templates = Jinja2Templates(directory="templates")

# 특정 페이지를 렌더링하는 예제
# 다음과 같이, 주소에서 {}를 통해 변수를 받아서 사용할 수 있습니다.
# 사용할 변수는 하단의 함수에서 추가로 정의해줘야합니다.
@app.get("/page/{name}", response_class=HTMLResponse)
def get_page(request: Request, name: str):
    return templates.TemplateResponse("page.html", {"request": request, "page": name})
구현해야 하는 페이지
  • index.html (메인)
  • hello.html (인사)

2단계: 데이터 보내기

목표: FastAPI에서 JSON 데이터를 반환하는 방법을 익힙니다.
  • 사용자 목록, 상품 목록 등 JSON 데이터 반환
  • 목업 데이터 파일(data/users.json, data/products.json) 활용
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명템플릿에서 받는 데이터
GET/usersusers.html
+ users.json (API)		사용자 목록(JSON) 반환
템플릿에서는 표로 출력		{ users: List[User] }
예: [{"id":1,"name":"홍길동","email":"hong@example.com"}, ...]
GET/productsproducts.html
+ products.json (API)		상품 목록(JSON) 반환
템플릿에서는 표로 출력		{ products: List[Product] }
예: [{"id":101,"name":"키보드","price":30000}, ...]
  • 각각 users.html, products.html에서 리스트를 표로 출력합니다.
    템플릿에서는 {% raw %}{% for user in users %}{% endraw %} ... {% raw %}{% endfor %}{% endraw %} 등 반복문 사용
필수 지식/예제
FastAPI JSON 반환 예제:
@app.get("/users", response_class=JSONResponse)
return users
구현해야 하는 페이지
  • users.html (사용자 목록)
  • products.html (상품 목록)

3단계: 복합적인 데이터(구매정보) 보내기

목표: 구매정보 목업 데이터(purchases.json)를 활용해, 구매자 이름, 상품명, 가격, 구매일시 등으로 조합된 정보를 반환하는 방법을 익힙니다.
  • 구매정보(purchases.json)에는 user_id, product_id, date만 있음
  • users.json, products.json과 조합하여 구매자 이름, 상품명, 가격, 구매일시 등으로 변환
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명템플릿에서 받는 데이터
GET/summarysummary.html
+ 구매정보 JSON		구매정보를 조합해 구매자, 상품명, 가격, 구매일시 등으로 반환
템플릿에서는 표로 출력		{ purchases: List[PurchaseSummary] }
예: {"purchases": [{"user_name": "홍길동", "product_name": "키보드", "product_price": 30000, "date": "2025-07-01T10:00:00"}, ...]}
  • summary.html에서 구매정보를 한 화면에 표로 출력
필수 지식/예제
구매정보 조합 예제:
return {"purchases": purchases_summary}
구현해야 하는 페이지
  • summary.html (구매 요약)

4단계: 데이터 CREATE하기

목표: POST 요청을 받아 새로운 데이터를 생성하는 방법을 익힙니다.
  • 사용자/상품/구매정보 추가 폼 구현 (HTML)
  • POST API로 데이터 추가
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명폼에서 전송/템플릿에서 받는 데이터
GET/user_createuser_create.html사용자 추가 폼 페이지없음 (폼에서 name, email 입력)
POST/usersJSON/리다이렉트폼에서 name, email을 받아 사용자 추가{ name: str, email: str }
폼에서 전송
GET/product_createproduct_create.html상품 추가 폼 페이지없음 (폼에서 name, price 입력)
POST/productsJSON/리다이렉트폼에서 name, price를 받아 상품 추가{ name: str, price: int }
폼에서 전송
GET/purchase_createpurchase_create.html구매정보 추가 폼 페이지없음 (폼에서 user_id, product_id, date 입력)
POST/purchasesJSON/리다이렉트폼에서 user_id, product_id, date를 받아 구매정보 추가{ user_id: int, product_id: int, date: str }
폼에서 전송
  • 폼에서 입력한 데이터는 POST로 전송됨
    예: {"user_id": 1, "product_id": 101, "date": "2025-07-01T10:00:00"}
필수 지식/예제
POST 데이터 받기 예제:
@app.post("/purchases")
def create_purchase(purchase: Purchase): ...
구현해야 하는 페이지
  • user_create.html (사용자 추가)
  • product_create.html (상품 추가)
  • purchase_create.html (구매정보 추가)

5단계: 데이터 수정 및 삭제하기

목표: PUT, DELETE 요청을 통해 데이터를 수정/삭제하는 방법을 익힙니다.
  • 수정/삭제 폼 구현 (HTML)
  • PUT, DELETE API 구현
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명폼에서 전송/템플릿에서 받는 데이터
GET/user_edit/{id}user_edit.html사용자 수정/삭제 폼 페이지
폼에서 name, email을 수정		{ user: { id, name, email } }
폼에서 name, email 입력
POST/users/{id}?_method=putJSON/리다이렉트사용자 정보 수정{ name: str, email: str }
폼에서 전송
POST/users/{id}?_method=deleteJSON/리다이렉트사용자 삭제id만 필요
GET/product_edit/{id}product_edit.html상품 수정/삭제 폼 페이지
폼에서 name, price를 수정		{ product: { id, name, price } }
폼에서 name, price 입력
POST/products/{id}?_method=putJSON/리다이렉트상품 정보 수정{ name: str, price: int }
폼에서 전송
POST/products/{id}?_method=deleteJSON/리다이렉트상품 삭제id만 필요
GET/purchase_edit/{id}purchase_edit.html구매정보 수정/삭제 폼 페이지
폼에서 user_id, product_id, date를 수정		{ purchase: { id, user_id, product_id, date } }
폼에서 user_id, product_id, date 입력
POST/purchases/{id}?_method=putJSON/리다이렉트구매정보 수정{ user_id: int, product_id: int, date: str }
폼에서 전송
POST/purchases/{id}?_method=deleteJSON/리다이렉트구매정보 삭제id만 필요
  • 폼에서 입력한 데이터는 POST로 전송됨
    예: {"user_id": 1, "product_id": 101, "date": "2025-07-01T10:00:00"}
필수 지식/예제
PUT/DELETE 예제:
@app.put("/purchases/{id}")
@app.delete("/purchases/{id}")
구현해야 하는 페이지
  • user_edit.html (사용자 수정/삭제)
  • product_edit.html (상품 수정/삭제)
  • purchase_edit.html (구매정보 수정/삭제)

6단계: 로그인 기능 만들기

목표: 세션/쿠키를 활용한 간단한 로그인 기능을 구현합니다.
  • 로그인 폼 구현 (HTML)
  • 로그인/로그아웃 API 구현
  • 로그인 상태에 따라 페이지 표시 다르게
필수 구현 API 및 사양서
MethodURL리턴(페이지)설명폼에서 전송/템플릿에서 받는 데이터
GET/loginlogin.html로그인 폼 페이지없음 (폼에서 username, password 입력)
POST/loginJSON/리다이렉트폼에서 username, password를 받아 로그인 처리{ username: str, password: str }
폼에서 전송
GET/logout리다이렉트로그아웃 처리없음
  • 로그인 폼에서 입력한 데이터는 POST로 전송됨
    예: {"username": "id", "password": "pw"}
필수 지식/예제
로그인 예제:
@app.post("/login")
def login(...): ...
구현해야 하는 페이지
  • login.html (로그인)
